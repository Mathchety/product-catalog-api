# Product Catalog API / API de Catálogo de Produtos

## 🇧🇷 Português

### 📝 Sobre o Projeto
Este é o meu primeiro CRUD completo desenvolvido utilizando **Java** com o framework **Spring Boot** e banco de dados **PostgreSQL**. O objetivo principal foi ir além do básico, aplicando padrões de mercado para construir uma API Rest funcional, segura e performática.

### 🚀 Funcionalidades e Boas Práticas
*   **CRUD Completo:** Criação, listagem, atualização e deleção de produtos.
*   **Padrão DTO (Data Transfer Object):** Implementado para garantir o desacoplamento das entidades do banco de dados e maior segurança na trafegabilidade dos dados.
*   **Paginação e Ordenação (Page/Pageable):** Aplicada nativamente nos endpoints de listagem geral e na busca customizada por nome, otimizando o consumo de memória do servidor.
*   **Tratamento de Exceções:** Retornos de erro padronizados e limpos para o cliente utilizando validações.

### 🛠️ Tecnologias Utilizadas
*   **Java 17** (ou a versão que você estiver usando)
*   **Spring Boot 3.x**
*   **Spring Data JPA**
*   **PostgreSQL**
*   **Maven**

## 🇺🇸 English

### 📝 About the Project
This is my first complete CRUD API developed using **Java** with the **Spring Boot** framework and a **PostgreSQL** database. The main goal was to go beyond the basics, applying industry standards to build a functional, secure, and high-performance REST API.

### 🚀 Features & Best Practices
*   **Full CRUD:** Product creation, retrieval, update, and deletion.
*   **DTO Pattern (Data Transfer Object):** Implemented to decouple database entities from the controller layer, ensuring secure data transfer.
*   **Pagination & Sorting (Page/Pageable):** Built natively into both the general listing and custom search-by-name endpoints, optimizing server memory usage.
*   **Exception Handling:** Clean and standardized error responses using custom validations.

### 🛠️ Technologies Used
*   **Java 17**
*   **Spring Boot 3.x**
*   **Spring Data JPA**
*   **PostgreSQL**
*   **Maven**
